# Security policy

Session Bridge handles private conversation history and writes to native client data for specifically verified versions. Please report suspected vulnerabilities privately so a fix can be prepared before technical details become public.

Use [GitHub's private vulnerability reporting form](https://github.com/pma1999/session-bridge/security/advisories/new). Include the affected version, platform, steps to reproduce, and the impact you observed. Use synthetic conversation data and redact credentials, tokens, personal paths, and conversation content from the report where possible.

Please do not open a public issue for an unpatched security vulnerability. This project does not currently publish a guaranteed response or remediation timeline.
